Terraform / AWS / Helm

EKS foundation

A modular Terraform project for provisioning an Amazon EKS cluster, from networking to storage and access controls.

View repository ↗
Design decisions & limits

Separate networking, the cluster, storage, and access into modules with explicit dependencies. Worker nodes run in private subnets.

Apply modules in dependency order. Account-specific IAM, state storage, and environment values need review before deployment; this is a starting point for a platform.

Most of my work is around Kubernetes, automation, and understanding what’s happening inside a running system. I like tools that are small enough to understand and useful enough to keep using.

Building apps brings the same questions into a different setting: what happens offline, how do you recover from a failed request, and how does someone know what to do next?
